# Public content policy

## Purpose

This repository publishes Matt Ricci's own language and a public-safe map of the sources that inform him. It does not rewrite his convictions into smoother assistant prose, republish source material, or expose private context merely because that context helped form a principle.

## Verbatim transport is the default

For principles, convictions, and working preferences:

1. Copy Matt's words verbatim from a named source.
2. Add an explicit provenance statement.
3. Keep editorial navigation and status text visibly separate.
4. Do not silently polish grammar, spelling, punctuation, or tone.
5. Do not turn fragments into a synthesized doctrine.
6. If no Matt-authored wording exists, mark the annotation as unwritten.

An interpretation may be added only when it is clearly labeled as interpretation and Matt has asked for one. It must never replace the source language.

## Required checks before publication

Every addition must be reviewed for:

1. **Authorship:** Is attributed prose actually Matt's wording?
2. **Provenance:** Does the file name the source from which the text was transferred?
3. **Attribution:** Are external ideas credited and linked to their canonical source?
4. **Copyright:** Does the file avoid transcripts, chapters, paywalled text, and substantial quotations?
5. **Work confidentiality:** Does it exclude non-public strategy, personnel, customers, patients, internal systems, prices, links, and communications?
6. **Personal privacy:** Does it exclude addresses, credentials, finances, health, contacts, schedules, and operational details?
7. **Behavioral value:** Will this help a reader or agent make a better decision, or is it merely an archive entry?

## Third-party sources

The public unit is Matt's annotation, not an archive. A source entry may contain bibliographic metadata, a canonical link, and Matt's own short note about what matters to him. Do not copy raw source files, transcript-shaped notes, or substantial guest or author quotations into this repository.

## Paid archives

Lenny's paid newsletter and podcast archive is a separate subscriber resource. Its raw files and transcript-shaped derivatives do not belong here. Public notes may cite an episode and contain Matt's original language without reproducing the episode.

## Private context boundary

This repository must not be generated wholesale from the private context pack. Material is promoted from a named source through deliberate public review. Work-specific application notes may be withheld while their public-safe episode or book metadata remains listed.

## Editorial text

Repository titles, navigation, bibliographic metadata, source labels, and status fields may be written editorially. They must not claim to be Matt's convictions. Phrases such as “To be added in Matt's words” are intentional safeguards, not incomplete assistant work.
