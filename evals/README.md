# Evaluations

> **Editorial scaffolding:** These are test-design ideas, not Matt-authored doctrine. Expected behavior must cite the verbatim principle it evaluates.

Evaluations test whether a collaborator or agent can apply Matt's principles—not merely quote them.

Candidate scenario families:

- distinguish false, unknown, stale, and loading states in a product design
- reduce scope without removing the outcome or necessary safety
- choose between written preparation and synchronous discussion
- preserve canonical context when evidence is distributed across links and conversations
- decide when a process is serving delivery and when it has become ceremony
- compare AI delivery options using quality, adoption, security, and total cost
- identify when public doctrine cannot answer a private organizational question

Each future evaluation should include the scenario, expected characteristics, unacceptable
responses, and the principle boundaries being tested.
